โปรเจกต์ WebAR ปฐมพยาบาลแผลไฟไหม้

ไฟล์ในโฟลเดอร์
- index.html : หน้า WebAR ใช้ A-Frame + MindAR
- poster-burn-first-aid.png : โปสเตอร์ที่ใช้เป็นภาพสแกน
- targets.mind : ต้องสร้างเองจากโปสเตอร์ก่อนใช้งานจริง

ขั้นตอนสร้าง targets.mind (ไม่ต้องติดตั้งโปรแกรม)
1. เปิด https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2. เลือกอัปโหลดไฟล์ poster-burn-first-aid.png
3. กดปุ่ม Compile และรอจนเสร็จ
4. ดาวน์โหลดไฟล์ targets.mind
5. นำ targets.mind มาใส่ไว้ในโฟลเดอร์เดียวกับ index.html

วิธีทดสอบ
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub repository ใหม่
2. เปิด Settings > Pages แล้วตั้ง Source เป็น Deploy from a branch
3. เลือก branch main และ folder /(root) แล้ว Save
4. เปิดลิงก์ GitHub Pages บนโทรศัพท์ผ่าน Safari หรือ Chrome
5. กดเริ่มสแกนโปสเตอร์และอนุญาตใช้กล้อง
6. เล็งกล้องไปที่โปสเตอร์จริง
7. เมื่อตรวจพบโปสเตอร์ ลากนิ้วซ้าย-ขวาบนหน้าจอเพื่อหมุนโมเดล

ข้อควรทราบ
- ต้องมี targets.mind ที่สร้างจากโปสเตอร์นี้จริง จึงจะสแกนได้
- ใช้งานกล้องผ่าน HTTPS เท่านั้น เช่น GitHub Pages
- โมเดลในต้นแบบนี้สร้างจากชิ้นส่วน 3 มิติของ A-Frame เพื่อให้ทดลองระบบสแกนและหมุนได้ก่อน ยังไม่ใช่โมเดลกายวิภาคระดับการแพทย์
- ภาพแผลเป็นสื่อการเรียนรู้ ไม่ใช้แทนการประเมินหรือรักษาจากบุคลากรทางการแพทย์
